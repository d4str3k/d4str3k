## Hi there!

I'm a cybersecurity engineer focused on **IoT security, application security, embedded systems and Linux**.

My work involves vulnerability assessment, penetration testing, security research and the development of cybersecurity labs and vulnerable environments.

### Featured Project

**[VulnZoo — IoT Cybersecurity Training & Research Lab](https://github.com/DEKRA-Cybersecurity/VulnZoo)**

VulnZoo is a hands-on cybersecurity laboratory designed to reproduce realistic attack surfaces across **IoT devices, mobile applications, APIs and web interfaces**.

The project combines:

* Embedded Linux and OpenWrt
* Raspberry Pi-based IoT devices
* Android applications
* REST APIs and backend services
* Docker and MongoDB
* BLE, TCP/IP and other IoT communication protocols
* Vulnerability research and exploitation
* Reproducible attack and mitigation scenarios

The goal is to provide realistic, reproducible environments for learning and researching IoT security.
